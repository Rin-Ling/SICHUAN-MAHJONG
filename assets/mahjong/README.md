# Mahjong Tile SVG Assets

The `tiles` directory contains 28 SVG files used by the Sichuan Mahjong calculator:

- `Man1.svg` through `Man9.svg`
- `Sou1.svg` through `Sou9.svg`
- `Pin1.svg` through `Pin9.svg`
- `Chun.svg`

Source:

https://github.com/FluffyStuff/riichi-mahjong-tiles
